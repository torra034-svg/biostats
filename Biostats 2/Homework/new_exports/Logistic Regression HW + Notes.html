Logistic Regression Notes

Which of the assumptions are checked for Logistic Regression?

  • Linearity

  • Independent observations

  • Normal distribution

  • Equal variance

  • basically LINE but on the log scale

What is the null hypothesis for a coefficient in a logistic regression model…

On the log-odds scale? H0: beta = 0; beta is log(odds)

On the odds ratio scale? H0: exp(beta) = 1; exp(beta) = odds ratio

What are two ways we can determine statistical significance of a coefficient in a logistic regression model?

  1. Confidence Interval does not include 1
  2. There is a dramatic change in the parameter coefficient

log model note: To run a logistic regression in R, use the glm() function and make sure to specify the family as binomial.

  • When writing down fitted model, you cannot simply write log(y) = intercept + (B1 x X1)
  • You must write logit([P(Y = 1)]) = intercept + (B1 x X1)
  • logit means log of the odds
  • You must write it in this form to since the we cannot simply take the log of a binary outcome, we must specify that the binary outcome is = 1 (or however it is coded)
  • Make sure when interpreting the coefficient, you must convert the log coefficient back to normal back exponentiating it (e.g j raise to the power of e)
  • Same thing when interpreting the odds ratio from the fitted formula. ALWAYS convert back to base by expatiating the values for interpretation.
