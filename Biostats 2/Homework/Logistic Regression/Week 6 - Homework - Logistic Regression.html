Diagnostic Checks

  • Note: for a logistic regression model, you cannot use the linear diagnostic plot functions.
  • Must use the following tests:
    • Likelihood Ratio Test = lrtest()
    • Variance Inflation Factor = vif()
      • This checks multicollinearity
    • Linearity of continuous predictors (see software Lesson06-LogisticR.pdf)
      • This checks linearity. How the continuous predictors are related to the log odds of the binary outcome
    • Hosmer-Lemeshow test = hoslem.test()
      • This checks goodness-of-fit
